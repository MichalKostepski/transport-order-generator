# Neutralny szablon PDF do demonstracji

Plik `template.pdf` jest **nowym, neutralnym szablonem demonstracyjnym**. Nie zawiera logo firmy ani prawdziwych danych.

Projekt z v4.4 ma pola formularza rozmieszczone za pomocą współrzędnych PDF. Ta demonstracyjna wersja pozwala uruchomić aplikację oraz sprawdzić generowanie i podgląd plików. **Nie jest wierną kopią firmowego układu** i nie jest przeznaczona do wystawiania prawdziwych zleceń.

W zastosowaniach operacyjnych konieczne jest dostosowanie i zweryfikowanie rozmieszczenia pól w `app/pdf_generator.py` do zatwierdzonego szablonu.
